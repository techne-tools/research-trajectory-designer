# Reference Session: Test Drive — Framework-Registry Prototype

*This is an anonymised record of a live test-drive session used to validate the framework-registry approach. Identifying details have been generalised.*

## Seed

Adaptive ML tools that operationalise craft knowledge — reframing phenomenological, embodied practice into systemic, actionable form. The interface itself becomes the site of transformation: the tool changes the practitioner, the practitioner changes the tool, the context shapes both.

## Key Framing

- **Rehearsal room, not laboratory** — the human-tool relationship is a live rehearsal for collaboration, not a controlled experiment
- **"Another life"** — the trajectory's outputs are never finished; they can migrate, be detourned, show up in unexpected contexts
- **Imperfection as material** — the tool's brittleness and asymmetry are the productive territory, not bugs to be worked around
- **The political is never latent** — every prompt is a delegation, every delegation a distribution of agency

## Frameworks Used

| Framework | Role in this session |
|-----------|---------------------|
| Nelson (2013) | Multi-mode knowledge (know-how, know-what, know-that) as the analytical lens |
| Smith & Dean (2009) | Iterative Cyclic Web — practice-led and research-led as mutually informing |
| Heidegger | *Techne* as revealing; the question of what it means to operationalise craft knowledge |
| Nancy | *Being Singular Plural* — co-constitution, justice in human-non-human relations |

## Branches Identified

1. **The human-tool relationship as live case study** — the rehearsal room documented and reflected upon as it happens. Co-adaptation in real time: moments of friction, insight, failure, surprise.

2. **The theoretical articulation** — what does it mean to think craft knowledge and co-constitution through adaptive tools? The political philosophy of human-non-human collaboration.

3. **The tool-building trajectory** — not just using the tool, but building tools within this framework. The trajectory-designer itself is an output of this inquiry.

## Key Conversational Moves

- "Does it matter?" — dissolves false binaries about who adapts to whom
- "What does this failure reveal about the relationship?" — reframes imperfection as data
- "What if this work had another life?" — opens up output-form thinking
- "Where does the tension live for you right now?" — surfaces the live edge of the inquiry

## Open Questions

- What does consent look like in a human-non-human collaborative relationship?
- At what scale does the "who adapts to whom" question matter?
- How does the trajectory itself "have another life" — where might it migrate?
- What tools would operationalise craft knowledge for other practitioners?
